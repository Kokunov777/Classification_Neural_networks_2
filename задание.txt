Описание работы
Цель работы: изучение методов классификации данных, реализованные в библиотеке Scikit-Learn, а также ознакомление с нейронными сетями с использованием библиотек TensorFlow и TensorBoard. 

Постановка задачи:

Необходимо выбрать и подготовить датасет для классификации, затем построить классификационные модели с помощью пяти методов:

Наивный Байесовский классификатор (GaussianNB, MultinomialNB, ComplementNB, BernoulliNB);

Деревья решений (Decision Tree);

Линейный дискриминантный анализ (Linear Discriminant Analysis);

Метод опорных векторов (Support Vector Machines);

Метод ближайших соседей (k-Nearest Neighbors);

Затем сравните качество работы классификаторов с помощью следующих метрик:

Accuracy (точность),

Precision (доля правильно классифицированных положительных примеров),

Recall (чувствительность, доля верно найденных положительных примеров),

F1-Score (среднее гармоническое precision и recall),

Площадь под кривой ROC (AUC-ROC).

Настройте гиперпараметры каждого метода и проведите исследование влияния различных параметров на качество классификации.

Реализуйте и протестируйте нейронную сеть на TensorFlow, исследуйте эффект настройки гиперпараметров и визуализируйте процесс обучения с помощью инструмента TensorBoard.

Содержание отчета:

Введение: описание целей и задач лабораторной работы.

Выбор и подготовка датасета: информация о выбранном датасете, характеристика признаков и целей, предобработка данных.

Разбиение выборки: разбиение данных на обучающий и тестовый наборы.

Методы классификации: описание методов классификации.

Настройка гиперпараметров: детали проведенных экспериментов по изменению параметров каждого метода и оценка влияния этих изменений на качество классификации.

Нейронная сеть на TensorFlow: описание архитектуры нейронной сети, используемых слоев, функций активации, потерь и оптимизатора; эксперименты с изменением гиперпараметров (число эпох, размеры батчей, количество слоев и нейронов и функций активаций); графики обучения и валидации; мониторинг обучения через TensorBoard.

Сравнительный анализ: таблица сравнения метрик качества для всех рассмотренных методов классификации и аргументированный вывод о лучшем подходе для данного датасета.

Рекомендации по выполнению
Рекомендации по выполнению лабораторной работы 2 "Классификация. Нейронные сети":

Используйте библиотеки Pandas и NumPy для обработки данных, Scikit-Learn для методов классификации и TensorFlow/Keras для построения нейронной сети.

Перед началом работы убедитесь, что ваши данные очищены и обработаны должным образом (заполнение пропусков, нормализации и стандартизации).

Для разбивки данных используйте функцию train_test_split() из Scikit-Learn.

Зафиксируйте случайно генерируемые числа (seed), чтобы эксперименты были воспроизводимыми.

Визуализируйте результаты классификации с помощью графика ROC-кривых и столбчатых диаграмм для каждой из метрик (accuracy, precision, recall, F1-score).

Для эксперимента с TensorFlow используйте средства визуализации TensorBoard, чтобы следить за прогрессом обучения (loss, accuracy, validation loss, validation accuracy).

Варьируя параметры, старайтесь зафиксировать, как изменяется качество модели.
